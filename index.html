01

Android — apk с GitHub Releases. iOS и десктоп — PWA, добавляется на экран за 10 секунд.

// Вопросы

Частые вопросы

Это бесплатно?

Да, полностью. Поддержать разработку можно добровольно — через Boosty, в разделе выше, но это ни на что не влияет.

Мои данные видят другие пользователи?

Нет. Row-Level Security на уровне Postgres: каждый видит только свои привычки, тренировки и записи — это гарантия базы данных, а не только интерфейса.

На каких устройствах это работает?

Android — apk из GitHub Releases. iOS, десктоп и любой браузер — как PWA, устанавливается на экран одним тапом.

Исходный код открыт?

Да, репозиторий на GitHub — ссылка в разделе установки выше.
