Установить Almanac

v…
Или сразу открыть сайт, без установки →

Android

Прямая установка apk, без Google Play

Скачать APK →
  1. 01Откройте ссылку на телефоне.
  2. 02Разрешите установку из неизвестных источников, когда система спросит.
  3. 03Зарегистрируйтесь прямо в приложении — почта и пароль, бесплатно.

Windows

Нативное приложение (Tauri), не PWA

Скачать для Windows →
  1. 01Скачайте и запустите установщик.
  2. 02Если Windows Defender предупредит — «Подробнее» → «Всё равно выполнить» (сборка пока не подписана платным сертификатом).
  3. 03Зарегистрируйтесь прямо в приложении — почта и пароль, бесплатно.

macOS

Нативное приложение (Tauri), не PWA

Скачать для macOS →
  1. 01Откройте .dmg и перетащите Almanac в Applications.
  2. 02Gatekeeper заблокирует первый запуск («файл повреждён») — это нормально для неподписанной сборки: правый клик по иконке → «Открыть» → «Открыть» ещё раз.
  3. 03Зарегистрируйтесь прямо в приложении — почта и пароль, бесплатно.

Linux

AppImage — универсальный, работает везде

Скачать AppImage →
  1. 01Скачайте файл и дайте ему права на запуск: chmod +x Almanac*.AppImage.
  2. 02Запустите двойным кликом или из терминала. Нужны .deb или .rpm — оба лежат на странице релиза.
  3. 03Зарегистрируйтесь прямо в приложении — почта и пароль, бесплатно.

iOS / iPadOS

Нативного билда пока нет — через Safari как PWA

Открыть Almanac →
  1. 01Откройте ссылку выше в Safari (обязательно в Safari, не в Chrome).
  2. 02Кнопка «Поделиться» → «На экран «Домой»».
  3. 03Зарегистрируйтесь прямо в приложении — почта и пароль, бесплатно.
